# NURSULTAN Studio

NURSULTAN writes the song; Suno performs it.

Builds for macOS and Windows are on the [Releases](https://github.com/yamtihoni/nursultan-releases/releases) page.
The app checks here for new versions: Help → Check for Updates…

- **macOS:** `NURSULTAN-macos.zip`. Unzip and move NURSULTAN to Applications.
- **Windows:** `NURSULTAN-windows.zip`. Unzip, run `Install AI models.cmd` once for the local models, then
  `NURSULTAN.exe`.
